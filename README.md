# Strategy Lab

Бесплатная платформа для исследования и тестирования торговых стратегий на исторических данных Binance Spot (публичные рыночные данные, без API-ключа). Public Beta.

## Возможности

- **Портфели** — собрать портфель из нескольких инструментов Binance Spot (по умолчанию котируемых в USDT), задать распределение капитала (равный капитал / вручную), размер позиции округляется вниз до `stepSize` инструмента автоматически. Портфель не может смешивать инструменты с разными валютами котировки (конвертации курса нет).
- **Multi-strategy** — на каждый инструмент можно назначить свою стратегию (или несколько сразу) и получить результаты по каждой отдельно, не смешивая сделки.
- **Historical backtesting** — бэктест по всему портфелю или части, с историей всех прошлых запусков, фильтрами и повтором конфигурации одной кнопкой.
- **Interactive candlestick charts** — независимые друг от друга плитки графиков (масштаб/диапазон/тикер одной плитки не влияют на другие, если явно не включена синхронизация), инструменты рисования, индикаторы, полноэкранный режим.
- **Trade visualization** — сделки бэктеста на интерактивном графике: вход/выход, стоп/тейк, причина закрытия.
- **Market Replay** — пошаговое ручное воспроизведение истории в духе TradingView Bar Replay: следующий бар не раскрывается до того, как наступил его момент (структурно исключён look-ahead), ручная торговля с комиссией и проскальзыванием.
- **Technical analysis** — набор индикаторов (EMA/SMA/WMA/VWAP/RSI/MACD/Bollinger/Stochastic/ATR/Momentum и др.), watchlist, сохраняемые layout'ы графиков.
- **Strategy optimization** — перебор параметров стратегии по сетке (до 5000 комбинаций) с ранжированием по нескольким метрикам.
- **Binance historical data** — данные загружаются через публичный Binance Spot REST API (`data-api.binance.vision`, без API-ключа) инкрементально: уже загруженный диапазон не скачивается повторно, довскачивается только недостающее. Единое хранилище свечей (`market_data_store`) — общий источник данных для графиков, бэктеста, портфеля, оптимизатора и Market Replay.
- **Backtest history** — сохранённые результаты каждого запуска с полным списком сделок, экспортом в CSV/JSON.
- **Аккаунты** — бесплатная регистрация, личный кабинет с историей своих бэктестов, портфелей и избранных инструментов (см. раздел «Аккаунты» ниже).

## Стратегии

Реализованные системные стратегии (см. `strategies/`):

| Стратегия | Категория | Идея |
|---|---|---|
| Ложный пробой 2R | Уровни | Прокол уровня поддержки/сопротивления и быстрый возврат за него |
| Голова и плечи | Паттерны | Разворотная фигура с пробоем линии шеи |
| Пробой с ретестом | Уровни | Выход из диапазона и проверка уровня с обратной стороны |
| Откат к EMA | Тренд | Вход по тренду после отката к быстрой EMA |
| Разворот RSI | Осцилляторы | Возврат RSI из зон перепроданности/перекупленности |
| Внутренний бар | Price Action | Сжатие диапазона (inside bar) и последующий выход |
| Пин-бар | Price Action | Свеча с длинной тенью у локального экстремума |

Актуальный список стратегий также доступен в реальном времени по `/api/strategies`.

### Модель бэктеста

Чтобы результаты можно было доверять:

- **Исполнение**: сигнал определяется на закрытии бара, вход исполняется по цене **открытия следующего бара** (не задним числом по уже известной цене).
- **Стоп/тейк в одном баре**: если в пределах одного бара были задеты и стоп-лосс, и тейк-профит, засчитывается срабатывание **стоп-лосса** (консервативное допущение).
- **Комиссия**: 0.05% за сторону (0.1% за сделку) учитывается во всех системных стратегиях.
- **Проскальзывание**: в автоматическом бэктесте **не моделируется** (Market Replay при ручной торговле — моделирует). Это явно указано под результатами каждого бэктеста в интерфейсе.

## Market Replay

Ручное пошаговое тестирование: выбираете тикер и дату/время начала, дальше — Play/Пауза/Пробел, стрелки вперёд/назад, скорость воспроизведения, переход к произвольной дате. Ни график, ни индикаторы, ни ручные сделки не могут получить доступ к барам «из будущего» относительно текущей точки воспроизведения — это гарантируется на уровне запроса к БД (`LIMIT reveal_index`), а не фильтром поверх уже готовых данных.

## Аккаунты

Регистрация и вход полностью бесплатны, платных тарифов нет.

**Без регистрации** доступно всё: собрать портфель, запустить бэктест, посмотреть графики, Market Replay — как и раньше, для пользователя без аккаунта.

**С регистрацией** дополнительно:

- личный кабинет (`/account`) — сводка, история своих бэктестов, свои портфели, избранные инструменты, настройки профиля/пароля;
- бэктесты и портфели, созданные в аккаунте, привязаны к нему и видны только вам — не как общий список для всех посетителей;
- избранные инструменты синхронизируются между устройствами (а не только в localStorage браузера).

Портфели и бэктесты, созданные без входа (или существовавшие до появления аккаунтов), остаются общими/видимыми всем — как и было в этом приложении изначально.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

Локально (dev-сервер Flask):

```bash
python app.py
# http://127.0.0.1:5050
```

Production (за nginx, см. `deploy/`) — через gunicorn, `SECRET_KEY` обязателен (см. `.env.example`):

```bash
pip install gunicorn
cp .env.example .env   # заполните SECRET_KEY: python -c "import secrets; print(secrets.token_hex(32))"
gunicorn --workers 2 --threads 4 --timeout 300 --bind 127.0.0.1:5060 app:app
```

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

## Структура

- `app.py` — Flask-приложение и основной API.
- `auth.py`, `auth_db.py`, `auth_routes.py`, `csrf.py` — аккаунты: сессии, хранилище пользователей, регистрация/вход/личный кабинет, CSRF.
- `strategies/` — реализации стратегий.
- `portfolio_engine.py`, `portfolio_store.py` — движок и хранилище портфелей.
- `backtests_db.py` — история бэктестов (SQLite).
- `replay_engine.py`, `replay_db.py` — Market Replay.
- `optimizer.py` — перебор параметров стратегии.
- `binance_client.py`, `binance_catalog.py`, `binance_market_data.py` — адаптер к публичному Binance Spot API (HTTP-сессия с ретраями, каталог инструментов через `exchangeInfo`, загрузка/пагинация свечей).
- `candle_api.py`, `market_data_store.py`, `market_data_sync.py` — единое хранилище и синхронизация исторических свечей Binance (без синтетических/восстановленных баров).
- `timeframes.py` — таймфреймы: нативные интервалы Binance + `10m` как единственный агрегат (из двух `5m`), `60m` — алиас `1h`.
- `market_ticker.py` — realtime-котировки (24h REST-тикер) и статусы `live/stale/disconnected`; потоковые данные графика фронтенд получает напрямую с публичного Binance WebSocket, без прокси через бэкенд.
- `rate_limit.py` — защита от перегрузки (rate limiting + ограничение одновременных тяжёлых операций).
- `static/chart-engine/` — движок графиков (независимые плитки, индикаторы, инструменты рисования).
- `templates/`, `static/` — интерфейс.
- `tests/` — автотесты (pytest).
