# MOEX Strategy Lab

Локальная HTML-панель для:

- скачивания свечей через MOEX ISS API;
- выбора тикера, периода и таймфрейма;
- запуска стратегии «Ложный пробой уровня»;
- запуска стратегии «Голова и плечи»;
- настройки параметров;
- просмотра итоговых метрик;
- скачивания CSV со сделками и JSON-сводки.

## Запуск на Windows

1. Распакуйте архив.
2. Дважды нажмите `ЗАПУСТИТЬ.bat`.
3. Откроется браузер по адресу `http://127.0.0.1:5050`.

При первом запуске установятся Python-библиотеки.

## Структура

- `app.py` — Flask-сервер и API панели.
- `downloader.py` — загрузка свечей MOEX с пагинацией.
- `templates/index.html` — интерфейс.
- `static/app.js` — работа интерфейса.
- `static/styles.css` — оформление.
- `strategies/false_breakout.py` — ложный пробой.
- `strategies/head_shoulders.py` — голова и плечи.
- `data/` — скачанные котировки.
- `results/` — результаты запусков.

## Важно

MOEX не отдаёт 15-минутные свечи напрямую. Доступные интервалы включают 1, 10, 60 минут и дневные свечи.

Панель предназначена для исследовательского тестирования. Историческая доходность не гарантирует будущий результат.
