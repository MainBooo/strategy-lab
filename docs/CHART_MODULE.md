# Модуль графиков («Анализ графиков»)

Пользовательский обзор вкладки «Анализ графиков» — таймфреймы/диапазоны,
мультиграфики, синхронизация, fullscreen, отображение сделок бэктеста. Для
внутреннего устройства кода (как добавить индикатор/инструмент рисования,
тайм-зоны, hit-testing) см. `docs/chart-engine.md`.

## Таймфрейм vs диапазон — два разных переключателя

Специально не смешаны в один контрол:

- **Таймфрейм** — период одной свечи: 1м / 10м / 30м / 1ч / 4ч / 1д / 1мес.
- **Диапазон** — видимый горизонт истории: 1Д / 5Д / 1М / 3М / 6М / 1Г / 5Л /
  Все.

30м и 4ч не хранятся отдельно — честно агрегируются из 10м/1ч
(см. `docs/HISTORICAL_DATA.md`).

## Верхняя панель

- Тикер, площадка, таймфрейм — селекторы слева.
- Баланс портфеля (равенство последнего **завершённого** бэктеста активного
  портфеля, не live-счёт — в приложении нет живой торговли, см.
  `GET /api/portfolios/<id>/summary`) — виджет в глобальной шапке приложения,
  виден на всех вкладках.
- OHLC текущей (или наведённой курсором) свечи и изменение — в заголовке
  каждой плитки графика: «ОТКР / МАКС / МИН / ЗАКР +Δ (±%)», обновляется живьём
  на новых данных и при наведении на конкретный бар.
- Кнопка полноэкранного режима — у каждой плитки отдельно и у всей рабочей
  области; выход — повторным нажатием той же кнопки (иконка меняется на
  «выйти») или Escape.

## Мультиграфики

Раскладки: 1 / 2 вертикально / 2 горизонтально / 2×2 / 3×2 (6 графиков).
Каждая плитка — независимый тикер/таймфрейм/индикаторы/рисунки. При
уменьшении раскладки убранные плитки не теряются — их конфигурация
архивируется и восстанавливается при возврате к большей раскладке (LIFO).

Кнопки переключения раскладки — фиксированный размер, понятная иконка
(мини-сетка точек, повторяющая раскладку), `active`/`hover`-состояния,
`title`-тултип, работают на мобильном (переключение раскладки — обычный tap).

## Синхронизация графиков (опционально)

Кнопка 🔗 в тулбаре включает/выключает синхронизацию **времени, масштаба и
перекрестия** между всеми открытыми плитками: панорамирование/зум одного
графика применяется к остальным, наведение курсора на одном показывает
перекрестие в той же точке времени на остальных. Состояние синхронизации
сохраняется в `localStorage` вместе с раскладкой. Каждая плитка защищена от
эффекта «эхо» (флаги `_applyingRange`/`_applyingCrosshair`) — применение
синхронизированного диапазона не порождает новую рассылку.

## Полноэкранный режим

Используется настоящий Fullscreen API браузера (не CSS-эмуляция с риском
«запереть» пользователя) с CSS-фолбэком на случай, если API недоступен —
и в фолбэк-режиме Escape тоже гарантированно работает (см. `fullscreen.js`).
Кнопка выхода всегда видна, независимо от того, каким путём фуллскрин был
открыт.

## Сделки бэктеста на графике

При открытии сохранённого бэктеста на графике сразу отрисовываются **все**
сделки (не по одной), с точками входа/выхода, направлением, стоп-лоссом,
тейк-профитом и итогом каждой сделки. Рендеринг — один canvas-примитив
(`TradeOverlayPrimitive`) поверх графика, а не DOM-элемент на каждую сделку —
сотни сделок не создают сотен узлов DOM и не тормозят панорамирование/зум.
Клик по маркеру сделки открывает карточку с деталями (цена/лоты/R:R/MAE-MFE/
комиссия).

## Правый sidebar — список тикеров

Поиск, вкладки «Все инструменты» / «Избранное» / «Портфель», текущая цена и
изменение (один пакетный запрос `/api/market/prices`, не по тикеру), быстрый
переход по клику, сворачивание в узкую полосу на десктопе / выезжающий drawer
на мобильном.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| Ctrl+Z / Ctrl+Shift+Z | Отменить / повторить последнее действие с рисунком |
| Delete | Удалить выбранный объект рисования |
| Escape | Выйти из полноэкранного режима |

(Горячие клавиши Market Replay — Пробел/←/→ — описаны отдельно в
`docs/MARKET_REPLAY.md`, это независимый режим со своим плеером.)
