# Strategy Lab

## Что добавлено

- Автоматический справочник всех акций доски TQBR через MOEX ISS.
- Поиск и выбор инструментов без ручного ввода тикеров.
- Мультискачивание выбранных инструментов.
- Автоматический официальный `LOTSIZE` для каждого тикера.
- Регулировка количества биржевых лотов на вход.
- Денежная симуляция с проверкой достаточности капитала.
- Подробный тултип возле каждого поля.
- Библиотека стратегий с визуальным кратким описанием.
- Основная стратегия: ложный пробой 2R.
- Дополнительные стратегии: голова и плечи, пробой с ретестом, откат к EMA, RSI-разворот, внутренний бар, пин-бар.
- Создание и удаление виртуальных портфелей.
- Отдельное число лотов для каждого инструмента портфеля.
- Аналитика портфеля: капитал, доходность, просадка, отклонённые сделки, результат по тикерам.

## Запуск

Распакуйте архив и запустите `ЗАПУСТИТЬ.bat`.

При первом открытии справочник MOEX будет загружен автоматически. Для этого требуется интернет.

## Важное замечание

Короткие продажи в денежной симуляции используют упрощённое резервирование полного номинала позиции. Реальные требования брокера по марже и доступности шорта могут отличаться.
