# Strategy Lab

- пакетный бэктест на нескольких CSV;
- оптимизатор параметров ложного пробоя;
- до 5000 комбинаций за запуск;
- рейтинг конфигураций;
- ограничения минимального и максимального риска;
- минимальное расстояние между касаниями;
- максимальный возраст уровня;
- только первый пробой уровня;
- фильтр ATR;
- выгрузка таблиц результатов в папку `results`.

Запуск: `ЗАПУСТИТЬ.bat`.
