# Strategy Lab

Улучшен выбор инструментов:
- вставка тикеров через запятую, пробел или новую строку;
- готовые наборы: ТОП-10, ТОП-20, банки, нефть и газ, металлургия, IT, все TQBR;
- чипы выбранных инструментов с быстрым удалением;
- копирование выбранного списка;
- сообщение о не найденных тикерах;
- кнопка скачивания недоступна, пока ничего не выбрано;
- понятная подсветка ошибки вместо системного alert.
